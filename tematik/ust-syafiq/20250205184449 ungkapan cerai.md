# BAB 

## Kalimat yg shorih 

Kalimat yang jelas artinya seperti "aku ceraikan engkau" maka jatuh talak

- tidak perlu niat dan semua madzhab sepakat 

{ فَإِن طَلَّقَهَا فَلَا تَحِلُّ لَهُۥ مِنۢ بَعۡدُ حَتَّىٰ تَنكِحَ زَوۡجًا غَیۡرَهُۥۗ فَإِن طَلَّقَهَا فَلَا جُنَاحَ عَلَیۡهِمَاۤ أَن یَتَرَاجَعَاۤ إِن ظَنَّاۤ أَن یُقِیمَا حُدُودَ ٱللَّهِۗ وَتِلۡكَ حُدُودُ ٱللَّهِ یُبَیِّنُهَا لِقَوۡمࣲ یَعۡلَمُونَ }
[Surah Al-Baqarah: 230]

- Ayat diatas tidak ada syarat harus niat

### Kalimat Talak yg shorih 

- Kalimat Talak
  - engkau diceraikan 
  - engkau aku ceraikan
  - dst yg mengandung makna jelas
- Firaq dan Tasrih

## Kalimat kinayah (yg multi tafsir)

- Tidak jatuh talak jika tidak diniatkan untuk menceraikan 

## Kalimat yg dikaitkan dengan waktu

- Jatuh talak jika waktu itu sudah datang

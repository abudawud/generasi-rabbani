# BAB Tafsir Surat Al Qadar 

{ بِّسۡمِ ٱللَّهِ ٱلرَّحۡمَـٰنِ ٱلرَّحِیمِ إِنَّاۤ أَنزَلۡنَـٰهُ فِی لَیۡلَةِ ٱلۡقَدۡرِ }
[Surah Al-Qadr: 1]

- Kata إِنَّاۤ adalah taukid
- kata أَنزَلۡنَـٰهُ adalah Khabar filiah 
- kata ganti هُ adalah untuk Al-Qur'an menunjukkan Alquran itu sudah seharusnya ada dipikirannya manusia 
- ilmu tanasub adalah ilmu yg membahas hubungan antar surat 

{ وَمَاۤ أَدۡرَىٰكَ مَا لَیۡلَةُ ٱلۡقَدۡرِ }
[Surah Al-Qadr: 2]

- Kata وَمَاۤ menunjukkan orang arab belum pernah mengetahui kata لَیۡلَةُ ٱلۡقَدۡرِ
- kata لَیۡلَةُ ٱلۡقَدۡرِ diulang terus menerus tanpa dhomir menunjukkan agungnya malam ini

{ تَنَزَّلُ ٱلۡمَلَـٰۤىِٕكَةُ وَٱلرُّوحُ فِیهَا بِإِذۡنِ رَبِّهِم مِّن كُلِّ أَمۡرࣲ }
[Surah Al-Qadr: 4]

- Penyebutan Malaikat Jibril setelah malaikat menunjukkan kemuliaan kedudukan malaikat Jibril 

{ سَلَـٰمٌ هِیَ حَتَّىٰ مَطۡلَعِ ٱلۡفَجۡرِ }
[Surah Al-Qadr: 5]

- Sholat subuh termasuk pada bagian malam yang memiliki keutamaan Lailatul Qadar 

# Turunnya Al-Quran 

- Al-Qur'an diturunkan dari lauhul Mahfudz ke Baitul Izzah (langit dunia) pada malam Lailatul Qadar 
- Kemudian dari Baitul Izzah turun ke Nabi shalallahu alaihi wasallam secara berturut-turut selama 20 tahun
